# CSV to JSON File Converter
**Script to read CSV files and write into JSON file**

## Usage:
python csv_to_json.py <path/to/file.csv> <path/to/file.json>

## Description
Easily convert CSV file and write to a JSON file.

Process will exit if no CSV files is given or CSV file cannot be found. If no
JSON file is specified, the user is given the option to wite to a default file.

Removes key value pairs if value is missing for clean data with no null values.
